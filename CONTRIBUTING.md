# Contributing to Veritas-AI 🛡️

First off, thank you for considering contributing to Veritas-AI! It's people like you who make digital authenticity accessible to everyone.

## 🌈 How Can I Contribute?

### Reporting Bugs
* Check the [Issues](https://github.com/vedant-0789/Veritas-AI/issues) to see if the bug has already been reported.
* If not, create a new issue. Include a clear title, a detailed description, and steps to reproduce the bug.

### Suggesting Enhancements
* Open an issue with the tag "enhancement".
* Describe the feature you'd like to see and why it would be useful.

### Pull Requests
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request.

## 🛠️ Development Setup

Refer to the [Getting Started](README.md#getting-started) section in the main README for environment setup.

### Backend Development
* Follow PEP 8 style guidelines for Python.
* Ensure all new modules have corresponding tests in the `backend/tests/` directory.
* Run tests using `pytest` (if installed) or manually via the provided test scripts.

### Extension Development
* Use TypeScript for all new logic.
* Ensure consistent styling using Tailwind CSS.
* Test cross-browser compatibility (though primarily targeted at Chromium-based browsers).

## 📜 Code of Conduct
Please be respectful and professional in all interactions within this project.
